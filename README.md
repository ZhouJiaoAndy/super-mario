# 超级马里奥 · HTML5 Canvas 复刻

一个从零手写的经典横版跳跃游戏。**零依赖、零构建、零素材文件**——
所有像素美术都在运行时用 Canvas 画出来，所有音效和背景音乐都用 Web Audio 实时合成。

直接用浏览器打开 `index.html` 就能玩。

---

## 快速开始

```text
双击 index.html
```

或者起一个本地静态服务器（可选，非必需）：

```bash
npx serve .        # 或 python -m http.server
```

> 因为全部使用普通 `<script>`（非 ES Module），`file://` 直接打开也能正常运行。

## 游戏内容

**三个关卡**

| 关卡 | 主题 | 特点 |
| --- | --- | --- |
| `1-1` | 地上 | 经典开场：问号块、水管、食人花、板栗仔、乌龟、台阶、旗杆与城堡 |
| `1-2` | 地下 | 蓝色砖块、洞顶走廊、金币长廊、石柱阵、两处深坑 |
| `1-3` | 空中 | 全浮空平台跳跃，考验助跑与落点判断 |

**玩法系统**

- **形态**：小马里奥 → 大马里奥（蘑菇）→ 火焰马里奥（火花），可发射火球；受伤降一级
- **无敌星**：短时间彩虹闪烁，撞到敌人即秒杀，音乐切换为高速版本
- **敌人**：板栗仔（可踩扁）、乌龟（踩一下变龟壳，再碰会踢出去，龟壳能连撞敌人）、食人花（管道里升降，不可踩）
- **砖块交互**：顶问号块出金币/道具；大马里奥可顶碎砖块；顶砖块会掀翻站在上面的敌人
- **连踩加分**：不落地的连续踩敌按 100/200/400/500/800/1000/2000/4000/5000/8000 递增，超过后 1UP
- **金币**：100 枚加一条命
- **中继点**：每关中途有检查点，之后死亡从检查点复活
- **旗杆**：抓得越高分越多；滑到底后自动走进城堡，剩余时间按 50 分/单位折算
- **计时**：时间归零即死亡，剩 100 时会有催促音
- 最高分存在 `localStorage`

## 实现要点

**渲染**
内部分辨率固定 256×240（与 NES 一致），用 CSS `image-rendering: pixelated` 整数放大，
所以在任何屏幕上都保持像素质感而不会糊。

**美术**
角色是手写的 16×16 / 16×24 / 16×32 字符画，运行时逐像素转成离屏 Canvas；
大马里奥由「头 + 躯干 + 腿」三段拼接而成，火焰形态只是换一套调色板。
砖块、水管、问号块、山、云、城堡等按主题配色程序化生成，因此三个关卡各自有独立色调。
HUD 文字用内置的 5×7 位图字体，附带描边/投影选项。

**音频**
全部由振荡器实时合成：脉冲波用傅里叶级数构造（12.5% / 25% / 50% 占空比），
低音用三角波，鼓点用噪声 + 滤波器。三首 BGM 是原创旋律，由主循环以 0.3 秒前瞻量排程。

**物理**（单位：像素 / 帧 @60fps）

| 参数 | 值 |
| --- | --- |
| 走路 / 奔跑最高速 | 1.55 / 2.60 |
| 起跳初速 | −4.62（叠加水平速度加成，最高 −5.24） |
| 上升重力 / 下落重力 | 0.165 / 0.46（按住跳跃键维持低重力 ⇒ 可变跳跃高度） |
| 实测助跑跳高 | 5.05 格，到最高点水平 5.04 格，滞空 51 帧 |
| 实测原地跳高 | 3.90 格 |

另外实现了土狼时间（5 帧）和跳跃输入缓冲（6 帧），落地/起跳手感更宽容。

## 自检

项目自带一套无头测试与截图工具，全部只用 Node 内置模块（无 npm 依赖）：

```bash
node tools/smoke-test.js     # 181 项断言：关卡数据 / 精灵尺寸 / 跳跃性能 / 全流程模拟
node tools/preview.js        # 离屏渲染截图到 tools/preview/
```

`smoke-test.js` 会在 Node 里用 Canvas 桩件把游戏完整跑起来，覆盖：

- 关卡数据完整性（行宽、出生点、敌人落脚点、旗杆、城堡边界）
- 所有精灵的尺寸是否符合预期（能抓出像素画行数写错）
- 跳跃性能实测（对照关卡设计所需的 3 格坑 / 3 格台阶）
- 数千帧逻辑 + 渲染，逐关跑通，含降旗、通关、死亡复活、暂停、静音
- 强制触发各玩法分支：变身、火球、无敌星、缩小、死亡、顶各类砖块、收集金币、100 金币加命

`preview.js` 用一个自己实现的迷你光栅化器把真实游戏画面画进 PNG，
可以不开浏览器就核对美术与排版。

## 已知取舍

- 没有做「顶到隐藏 1UP 蘑菇」「藤蔓」「水下关」等更后期作品的要素
- 地下关没有做管道进出房间的切换，通关统一走旗杆
- 背景音乐是原创旋律（避免直接使用原作曲），风格上贴近 8-bit 欢快路线
